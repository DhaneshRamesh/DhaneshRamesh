## Selected systems

### Finlo

A cross-border financial decision platform for globally mobile borrowers. I work across a three-service architecture consisting of a React and TypeScript product interface, a FastAPI orchestration and persistence layer, and a Python ML service for income, foreign-exchange and repayment-risk modelling. The system includes versioned API contracts, request tracing, queued model training, artifact promotion and rollback, scenario history, explainable decision outputs and deterministic metric reproduction.

### AI Skill Recommender

A hybrid recommendation platform that extracts evidence from resumes and maps candidates to relevant roles and skills. The system combines deterministic graph rules with semantic inference, ranking and feedback workflows. It includes versioned FastAPI endpoints, PostgreSQL persistence, Cognito authentication, deployment templates and an extensive automated test suite. Reproducible evaluation across 60 structured skill-matching cases records 0.968 F1 and 1.000 recall for explicit extraction.

### ChaCha

A deployment-oriented marketing operations platform spanning social publishing, analytics, media monitoring, email campaigns and AI-assisted workflows. My contributions cover OAuth integrations, data pipelines, platform APIs, cloud infrastructure and operational-readiness work across TypeScript, PostgreSQL, Redis, Docker, Terraform and CI/CD.

### FiqueBot

An Azure-based retrieval-augmented generation system for customer support and knowledge search. The architecture combines FastAPI, Azure OpenAI, Microsoft Entra ID, Azure Blob Storage, Event Grid, content ingestion, citations and automated deployment workflows.
